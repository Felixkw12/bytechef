## Connection Setup

1. Login into your [Opper console](https://platform.opper.ai/).
2. Open **API Keys** and create a new API key.
3. Copy your API key and paste it into the **Token** field in ByteChef.
4. Done.

Model IDs are model names such as `claude-sonnet-4-5`, and Opper picks the provider for each request. To pin one provider, use the `provider/model` form, for example `anthropic/claude-sonnet-4-5`. The full list is available in the [Opper model catalogue](https://opper.ai/models).
